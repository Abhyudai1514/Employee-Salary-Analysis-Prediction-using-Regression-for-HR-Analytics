# 💼 Employee Salary Analysis & Prediction using Regression for HR Analytics

## 📌 Problem Statement
Organizations need accurate salary estimation models to ensure fair compensation and workforce planning. This project focuses on predicting employee salary based on work-related attributes, enabling data-driven compensation decisions.

---

## 📊 Dataset
The dataset contains employee-related attributes such as:

- Years at Company  
- Job Role / Department  
- Satisfaction Level  
- Average Monthly Hours  
- Promotion History  

---

## ⚙️ Tech Stack
- Python  
- Pandas, NumPy  
- Scikit-learn  
- Matplotlib  

---

## 🔍 Approach

1. Data cleaning and preprocessing  
2. Exploratory Data Analysis (EDA) to identify trends  
3. Feature selection based on impact on salary  
4. Data scaling using StandardScaler  
5. Model building using Linear Regression  
6. Model evaluation using MAE and RMSE  

---

## 🤖 Model
- Algorithm: Linear Regression  
- Preprocessing: StandardScaler for feature normalization  
- Performance: Evaluated using regression metrics (MAE, RMSE)  

---

## 📈 Key Insights
- Years of experience strongly influences salary  
- Working hours and satisfaction impact compensation trends  
- Promotions and job roles significantly affect salary distribution  

---

## 💡 Business Impact
- Helps in fair salary benchmarking  
- Supports HR decision-making  
- Improves workforce planning  
- Enables data-driven compensation strategies
